duplicat_env

Pick a real road, get a CARLA map (FBX + OpenDRIVE) and an Autoware map (Lanelet2 + PCD). Free data only: OpenStreetMap, OSRM, IGN, AWS Terrain Tiles.

    Click the map to add waypoints along the road. Drag markers to adjust, right-click one to delete it.
